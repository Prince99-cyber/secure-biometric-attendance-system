# Secure Biometric Attendance System

## Overview

A team project developed using Python, OpenCV, MediaPipe, and Tkinter that provides secure biometric attendance through face recognition, liveness detection, anti-spoofing verification, and automated attendance management.

## Features

- Face Recognition Authentication
- Liveness Detection
- Anti-Spoofing Verification
- Random Challenge Response
- Blink Detection
- Head Movement Detection
- Attendance Logging
- Intruder Detection
- GUI-Based Authentication
- Automatic Model Training

## Technologies Used

- Python
- OpenCV
- MediaPipe
- Tkinter
- NumPy
- LBPH Face Recognition
- Computer Vision

## Security Features

- Face Authentication
- Liveness Verification
- Anti-Spoofing Protection
- Intruder Image Capture
- Access Logging

## Attendance Logic

- First Scan → Entry Time
- Second Scan → Exit Time
- Entry After 09:00 AM → Half Day
- Exit Before 04:30 PM → Half Day
